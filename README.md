# Spiking Bug

Два связанных рабочих пространства для исследования импульсных нейронных сетей:
**окружение жука** и **редактор коннектома**. Один Python-сервер вычисляет сеть и
мир; оба интерфейса показывают одно состояние.

## Запуск

Нужны Python 3.10+ и Node.js 22.12+ (или 24 LTS).

```bash
./setup.sh
./run.sh
```

- Окружение: **http://127.0.0.1:5173**
- Коннектом: **http://127.0.0.1:5174**
- API: http://127.0.0.1:8000

Симуляция запускается на паузе. Кнопка «Запустить» действует сразу в обоих окнах.
Ctrl+C завершает все три процесса. На macOS можно открыть `start.command`.
На Windows: `python -m venv .venv`, `.venv\Scripts\python -m pip install -r requirements.txt`,
`npm ci`, затем `.venv\Scripts\python scripts/dev.py` (нужен доступный `npm`).
Это локальный исследовательский стенд; серверы слушают только 127.0.0.1.

## Что можно делать

**Среда**

- Масштабировать и перемещать большую арену, следовать камерой за жуком.
- Рисовать стены, размещать пищу и угрозы, задавать зоны появления пищи.
- Генерировать связные лабиринты с заданными размерами и seed.
- Выбирать статичные угрозы или преследование: обзор с учётом стен, ограниченное
  время интереса, отдых и повторный захват цели.
- Настраивать размеры мира, сенсоры, голод, усталость, количество объектов.
- Назначать **любой существующий ID нейрона** сенсорному или моторному каналу.
- Управлять вручную W/A/S/D через ток на назначенные моторные нейроны.
- Редактировать JSON мира или создавать сцены внешним скриптом.

**Коннектом**

- Создавать, выделять, перемещать, копировать и удалять нейроны; искать их по ID.
- Редактировать прямые и два модулирующих типа синапсов, веса и задержки.
- Управлять порогом, непрерывной утечкой, рефрактерностью, шумом и постоянным током.
- Оставлять потенциал после спайка (по умолчанию) или сбрасывать его в ноль.
- Генерировать ганглии: число нейронов, радиус, вероятность связи, доля E/I,
  полярность нейронов или отдельных связей, параметры LIF, воспроизводимый seed.
- Подключать синапс к коннектору ганглия: воздействие на всех его участников.
- Смотреть среднюю частоту спайков всей сети или ганглия и выгружать CSV.
- Сохранять/импортировать эксперименты и старые BUG-сети из `examples/legacy/`.

## Первые шаги

1. Откройте оба интерфейса. В окружении нажмите «Запустить» — пример управляется
   небольшой вручную заданной сетью. Автоматического обучения весов здесь нет.
2. В коннектоме выберите нейрон: инспектор покажет параметры и назначенные каналы.
3. Инструмент ↗: выберите нейрон-источник, затем получателя; настройте связь справа
   и нажмите «Создать связь». Для ганглия получателем служит ромб справа от круга.
4. Во вкладке «Генератор» создайте ганглий. Или инструментом ◉ задайте его центр
   и радиус непосредственно на поле.
5. В окружении вкладка «Нейроны» настраивает мост ID; изменения видны в коннектоме.
6. «Сохранить» записывает эксперимент в `data/project.json`, «Экспорт» скачивает
   переносимый JSON. После перезапуска он восстанавливается на паузе.

Рефрактерный период блокирует **только спайк**. Входы и утечка изменяют потенциал
каждый такт. Если после окончания периода потенциал выше порога, нейрон снова
стреляет без обязательного нового импульса. Модуляторы меняют чувствительность к
возбуждению или торможению и экспоненциально возвращаются к 1.

## Проверка и воспроизводимость

```bash
.venv/bin/python -m unittest discover -s tests -v
npm run build
npx playwright install chromium
# При запущенном ./run.sh:
npm run test:e2e
.venv/bin/python scripts/benchmark.py --output docs/benchmark-local.json
```

Браузерные тесты временно меняют открытый эксперимент, затем восстанавливают его.
Запускайте их без одновременного ручного редактирования. Для отдельного тестового
экземпляра используйте временный путь `python -m server.app --project /tmp/bug-test.json`
и оба Vite-клиента вместо основного API.

[Архитектура, уравнения и ограничения](docs/architecture.md) ·
[JSON и API](docs/format.md) · [Измерения производительности](docs/performance.md).

CPU-ядро использует разреженные связи и кольцевой буфер задержек. GPU-бэкенд не
реализован: решение о нём следует принимать по замерам конкретной нагрузки.
До 20 000 нейронов и 500 000 эффективных связей; индивидуальная телеметрия ограничена
первыми 2 000 нейронов, агрегаты учитывают всю сеть. Экспорт — описание эксперимента,
**не** checkpoint текущих потенциалов и летящих импульсов.

## Исходная версия

Проект переписан с новой структурой; исходные примеры BUG сохранены в
`examples/legacy/`. CartPole, MountainCar и автономная браузерная копия удалены.
Миграция сохраняет топологию, ID, веса, задержки и визуальные рамки. Численная
динамика новой версии намеренно отличается: интеграция непрерывна даже в
рефрактерный период, сброс — в ноль. Старые траектории не воспроизводятся побитно.

Отдельные процессы в разработке:

```bash
.venv/bin/python -m server.app
npm run dev:environment
npm run dev:editor
```

`npm run build` собирает два независимых каталога `dist/environment` и `dist/editor`.
Для внешнего развёртывания потребуются production WSGI, reverse proxy для `/api`
(с отключённой буферизацией SSE) и ограничение доступа; текущий launcher предназначен
для локальной работы.
