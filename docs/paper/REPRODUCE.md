- `figures/`: PDF с векторными графиками и PNG; восемь оригинальных снимков интерфейса (четыре на язык).
- `data/flattening_check.json`, `data/modulation_trace_check.json`, `data/saved_scene_check.json`: дополнительные проверки, не включённые в основные 480 эпизодов.
- `qa/`: журналы компиляции и результаты проверки итоговых PDF.

## Статистическая граница

60 seed являются повторами среды для каждой фиксированной схемы. Это не 60 независимо созданных сетей. Общий промпт уменьшает различие инструкций, но не доказывает беспристрастность генераций или равный бюджет оптимизации. Панель seed не подтверждена как отложенная относительно первоначальной работы LLM. Переход от 600 к 1200 с выполнен после просмотра ранних результатов и уточнения автором цели; рукопись прямо сообщает эту корректировку. Контроллеры не дорабатывались, seed не отбирались.

## Повторить вычисления

Сохраните исходную поставку: эти команды заменяют генерируемые файлы данных. На macOS использован Python 3.13 и версии пакетов из `requirements-reproduction.txt`. Для одного лишь CPU-расчёта сети нужен NumPy; Matplotlib используется для графиков. CUDA/MPS не использовались. Все пути ниже относятся к этому каталогу `docs/paper/`, поэтому комплект можно распаковать отдельно от репозитория.

```bash
python3 -m venv .venv-paper
.venv-paper/bin/python -m pip install -r requirements-reproduction.txt
.venv-paper/bin/python scripts/experiment.py --workers 4 --seeds 60 --horizon 1200
.venv-paper/bin/python scripts/trace_check.py
.venv-paper/bin/python scripts/saved_scene_check.py
.venv-paper/bin/python scripts/analyze.py
.venv-paper/bin/python scripts/export_tables.py
```

Основные параметры: seed 21000–21059; 1200 с; шаг 0.01 с; 3 исходные схемы, 2 абляции модуляции и 3 условия цены за нейроны 0.001. Первые три seed дополнительно используются для проверки развёртывания G. Повторяемость оценивается по поведенческим данным; `wall_seconds` зависит от машины и нагрузки.

## Собрать PDF

Нужен XeLaTeX с BibTeX или Tectonic. Все используемые текстовые шрифты Liberation Serif/Sans и DejaVu Sans Mono поставляются с лицензиями в `fonts/`; системные шрифты не требуются. Векторные графики уже содержат встроенные шрифты.

```bash
tectonic article-ru.tex
tectonic article-en.tex
```

Либо:

```bash
xelatex article-ru.tex
bibtex article-ru
xelatex article-ru.tex
xelatex article-ru.tex
xelatex article-en.tex
bibtex article-en
xelatex article-en.tex
xelatex article-en.tex
```
